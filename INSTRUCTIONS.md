## ⚠️ Notas Importantes

### Sobre los Datos
- Los datos se guardan en el **localStorage** del navegador
- Si usas el mismo navegador, los datos se recuperarán automáticamente
- Si limpiaste los datos del navegador, no se pueden recuperar
- Si cambiaste de navegador, los datos están en el navegador anterior

### Sobre la Migración
- La migración es **automática y transparente**
- Ocurre al iniciar sesión por primera vez
- Los datos antiguos se eliminan después de migrar
- No se pierden datos durante el proceso
